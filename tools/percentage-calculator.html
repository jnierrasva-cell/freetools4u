What this percentage calculator does

Solve common percentage questions: find a percentage of a value, calculate what percentage one value is of another, or measure percentage change between two values.

How to use it

Enter the two values and choose the calculation. For “A% of B,” enter the percentage as A and the base amount as B. For percentage share, enter the part as A and the whole as B. For percentage change, enter the starting value as A and ending value as B.

Important details and limitations

Percentage change uses the starting value as the reference and supports negative starting values. A zero starting value cannot be used as the denominator for percentage change. Check the inputs and units before relying on a result.
