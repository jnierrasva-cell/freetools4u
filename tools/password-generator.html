What this password generator does

Create a random password using the character groups you select. Choose a length from 8 to 128 characters and include uppercase letters, lowercase letters, numbers, and symbols.

How to use it

Choose the desired length and at least one character group, then select Generate password. Copy the generated result and store it in a reputable password manager. Generate a new password if you change any options.

Important details and limitations

The generator uses the browser's cryptographically secure random-number API and includes at least one character from each selected group. Password strength also depends on unique use, secure storage, and the security of the account where it is used.
