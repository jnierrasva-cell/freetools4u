What this duplicate line remover does

Clean up copied lists by removing repeated lines while keeping the first occurrence in its original position. Handy for contact lists, keyword lists, exported rows, and notes.

How to use it

Paste one item per line and select Remove duplicate lines. The result preserves the order of first appearances. Matching ignores leading and trailing spaces, while the displayed first line remains unchanged.

Important details and limitations

Blank lines are treated as lines too, so repeated blank lines are reduced to one. Matching is case-sensitive: Apple and apple are considered different entries. Review the output before using it as a data import.
