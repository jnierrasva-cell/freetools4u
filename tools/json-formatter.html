What this json formatter does

Format compact JSON into an indented, readable structure, or minify valid JSON to reduce whitespace. The browser also checks whether the input can be parsed as JSON.

How to use it

Paste JSON into the input box. Select Format JSON to indent it, or Minify JSON to remove unnecessary whitespace. If parsing fails, read the error message and check commas, quotation marks, braces, and brackets.

Important details and limitations

The formatter validates JSON syntax but does not validate your data against an API schema or business rules. Do not paste secrets, access tokens, or private customer records into tools on shared devices.
