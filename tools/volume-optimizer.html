Volume Optimizer

Boost audio from a supported browser tab beyond its original playback level. Adjust amplification and peak control in real time.

Inactive
100% is the captured tab's original digital level. Increase gradually; high levels can still sound distorted.
Start with Light or Off. Strong compression can make background hiss and sharp sounds more noticeable.

How to use

  1. Open the video or audio in a separate browser tab.
  2. Return here and select Select browser tab audio.
  3. In the browser sharing picker, select the media tab and enable Share tab audio.
  4. Start at 100%, then raise the boost gradually.
  5. Select Stop boosting before choosing another source.
Browser-only limitation: This tool processes audio that your browser allows it to capture. It cannot directly control every Windows desktop application. The original tab may continue playing alongside the processed audio, so use headphones if you hear duplicate playback or echo.

About browser-tab audio processing

This tool captures audio from a browser tab using the browser screen-sharing permission picker, then routes the captured audio through a gain control and dynamics compressor. It does not install a driver or change the Windows master volume.

Compatibility and limitations

Support depends on your browser, operating system, and the sharing options you select. Choose a browser tab and enable tab audio when prompted. Some browsers or devices may not offer audio capture. The source tab may also play through its normal output, which can create echo or doubled sound.

Audio is processed in the current browser session using the Web Audio API. Stop sharing to end capture. Do not use this tool as a hearing-safety device; keep playback at a comfortable level.
