Volume Optimizer

Boost audio from a supported browser tab beyond its original playback level. Adjust amplification and peak control in real time.

Inactive
100% is the captured tab's original digital level. Increase gradually; high levels can still sound distorted.
Gentle compression can reduce loud peaks. It is not a guarantee against clipping or source distortion.

How to use

  1. Open the video or audio in a separate browser tab.
  2. Return here and select Select browser tab audio.
  3. In the browser sharing picker, select the media tab and enable Share tab audio.
  4. Start at 100%, then raise the boost gradually until the level is comfortable.
  5. Select Stop boosting before choosing another source.
Browser-only limitation: This web tool processes audio that the browser allows it to capture. It cannot directly control or capture every Windows desktop app. Do not select this optimizer tab as its own source. Avoid capturing system audio while the original app is also playing through another route, as duplicate playback can cause echo.
